# openporch_environment_type_user (Resource)

A member's role on an environment type. The only role is `deployer`, which lets the member deploy to environments of the type, create and delete them, and change their values. Only administrators grant it. Import it as `TYPE/USER`.

## Example Usage

```terraform
# Lets the service user deploy to every environment of the type.
resource "openporch_environment_type_user" "ci" {
  env_type_id = openporch_environment_type.staging.id
  user_id     = openporch_user.ci.id
  role        = "deployer"
}
```
