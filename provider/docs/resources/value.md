# openporch_value (Resource)

A shared value of an application, or of one of its environments, which overrides the application's. Workloads read it as `${values.KEY}`. It holds exactly one of a plain `value`, a `secret_value` written to the built-in secret store, or a `secret_ref` to a secret already in a store. A `secret_value` is kept in the OpenTofu state, so protect the state; see the provider documentation. Import it as `APP/KEY` or `APP/ENV/KEY`.

## Example Usage

```terraform
resource "openporch_value" "log_level" {
  app_id = openporch_application.shop.id
  key    = "LOG_LEVEL"
  value  = "info"
}

# An environment value overrides the application value with the same key.
resource "openporch_value" "log_level_staging" {
  app_id = openporch_value.log_level.app_id
  env_id = openporch_environment.staging.id
  key    = openporch_value.log_level.key
  value  = "debug"
}

# A secret value is written to the built-in store and tracked by version.
resource "openporch_value" "api_key" {
  app_id       = openporch_application.shop.id
  key          = "PAYMENT_API_KEY"
  secret_value = var.payment_api_key
}
```

## Schema

### Required

- `app_id` (String) The application.
- `key` (String) The key: letters, digits, `_` and `-`, starting with a letter or `_`.

### Optional

- `description` (String) A description.
- `env_id` (String) The environment, for an environment value. The application must have a value with the same key.
- `secret_ref` (Attributes) A reference to a secret in a store. Referencing a secret openporch did not write needs a secret-use grant. (see [below for nested schema](#nestedatt--secret_ref))
- `secret_value` (String, Sensitive) A secret, written to the built-in store. Changing it writes a new version. The server never returns it; `written_secret_ref` records the version written, and a version changed outside OpenTofu plans a write of this value again.
- `value` (String) A plain value.

### Read-Only

- `written_secret_ref` (Attributes) Where `secret_value` was written. (see [below for nested schema](#nestedatt--written_secret_ref))
