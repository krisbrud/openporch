# openporch_application (Resource)

An application. It is created with a `development` environment, and the provider's user becomes its `owner`. Deleting it deletes every environment and the resources they own, behind `destroy_acknowledgements`. Import it by ID.

## Example Usage

```terraform
resource "openporch_application" "shop" {
  id   = "shop"
  name = "Web shop"

  # Deleting the application deletes the cloud resources it owns; list them
  # here, as the deletion error prints them (with @FINGERPRINT when it shows
  # one), before removing it.
  destroy_acknowledgements = [
    "development:postgres.default#modules.web.externals.db=delete",
  ]
}
```

## Schema

### Required

- `id` (String) The application ID. Changing it replaces the application.

### Optional

- `destroy_acknowledgements` (Set of String) Acknowledges the resources that deleting this object deletes, each written `ENV:DESCRIPTOR=ACTION` (with `@FINGERPRINT` when the preview shows one). Deleting it previews the deletion first and deletes nothing unless every resource the preview marks is acknowledged; the error lists the entries to add. Set them, apply, and then remove the object (if it is already removed from the configuration, put it back with the entries first). Entries for changes the preview does not show are ignored.
- `name` (String) The display name, 1 to 100 characters without surrounding spaces. Defaults to the ID when the object is created.
