# openporch_resource_class (Resource)

A class of a resource type, such as `large` for `postgres`. Workloads ask for a class, and resource definitions match on it. Every type has the `default` class, which is not managed here. A class cannot be changed, so any change replaces it. Import it as `TYPE/CLASS`.

## Example Usage

```terraform
resource "openporch_resource_class" "large" {
  resource_type = "postgres"
  id            = "large"
  description   = "Databases with more memory"
}
```
