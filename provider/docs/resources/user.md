# openporch_user (Resource)

A service user, for CI and automation. People join through invitations and are not managed here. Deleting a service user revokes its tokens and removes its roles. Import it by ID.

## Example Usage

```terraform
# A service user, such as the one a CI pipeline deploys as.
resource "openporch_user" "ci" {
  id   = "ci"
  name = "CI pipeline"
  role = "member"
}
```

## Schema

### Required

- `id` (String) The user ID. Changing it replaces the user.
- `role` (String) The organization role: `administrator`, `manager`, `member` or `orgViewer`. Granting a role needs authority over it.

### Optional

- `name` (String) The display name, 1 to 100 characters without surrounding spaces. Defaults to the ID when the object is created.
