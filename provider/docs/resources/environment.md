# openporch_environment (Resource)

An environment of an application. Creating one needs `developer` on the application and `deployer` on the type. Every application already has `development`, which goes with the application and is not managed here. Deleting an environment deletes the resources it owns, behind `destroy_acknowledgements`. Import it as `APP/ENV`.

## Example Usage

```terraform
resource "openporch_environment" "staging" {
  app_id = openporch_application.shop.id
  id     = "staging"
  type   = openporch_environment_type.staging.id
}
```

## Schema

### Required

- `app_id` (String) The application. Changing it replaces the environment.
- `id` (String) The environment ID. Changing it replaces the environment.
- `type` (String) The environment type. Changing it replaces the environment.

### Optional

- `destroy_acknowledgements` (Set of String) Acknowledges the resources that deleting this object deletes, each written `DESCRIPTOR=ACTION` (with `@FINGERPRINT` when the preview shows one). Deleting it previews the deletion first and deletes nothing unless every resource the preview marks is acknowledged; the error lists the entries to add. Set them, apply, and then remove the object (if it is already removed from the configuration, put it back with the entries first). Entries for changes the preview does not show are ignored.
- `name` (String) The display name, 1 to 100 characters without surrounding spaces. Defaults to the ID when the object is created.
