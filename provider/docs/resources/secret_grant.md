# openporch_secret_grant (Resource)

A secret-use grant: lets an application, one of its environments, or the whole organization use one reference that it did not write. Holding a reference is not permission to use it; deployments check grants right before they read a secret, so deleting a grant blocks every later use, including replays. A grant cannot be changed, so any change replaces it. Import it as `STORE/GRANT_ID`.

## Example Usage

```terraform
# Lets production of the shop use a secret someone else put in the store.
resource "openporch_secret_grant" "stripe" {
  store  = openporch_secret_store.vault.id
  ref    = "shop/stripe-key"
  app_id = openporch_application.shop.id
  env_id = "production"
}
```

## Schema

### Required

- `ref` (String) The reference in the store, without a version: a grant covers every version.
- `store` (String) The store, such as `openporch` or an `openporch_secret_store`'s ID.

### Optional

- `app_id` (String) The application allowed to use the secret. Conflicts with `org_wide`.
- `env_id` (String) Narrows the grant to one environment of `app_id`.
- `org_wide` (Boolean) Usable everywhere in the organization, meant for platform definitions. Conflicts with `app_id`.

### Read-Only

- `id` (String) The grant ID, chosen by the server.
