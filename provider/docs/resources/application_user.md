# openporch_application_user (Resource)

A member's role on an application: `viewer`, `developer` or `owner`. Granting a role needs `owner` on the application and authority over the role. The application's creator is already its owner. Import it as `APP/USER`.

## Example Usage

```terraform
resource "openporch_application_user" "ci" {
  app_id  = openporch_application.shop.id
  user_id = openporch_user.ci.id
  role    = "developer"
}
```
