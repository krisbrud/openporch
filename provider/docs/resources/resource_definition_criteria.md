# openporch_resource_definition_criteria (Resource)

One matching criterion of a resource definition. A definition matches a resource when any of its criteria matches, and a criterion matches when every attribute it sets matches; one that sets nothing matches every resource of the `default` class. A criterion cannot be changed, so any change replaces it. Replacing the definition (by changing its `type`) deletes its criteria; give each criterion `lifecycle { replace_triggered_by = [openporch_resource_definition.NAME] }` to recreate them in the same apply. Import it as `DEFINITION/CRITERION`.

## Example Usage

```terraform
resource "openporch_resource_definition_criteria" "staging" {
  resource_definition_id = openporch_resource_definition.redis.id
  env_type               = "staging"

  # Changing the definition's type replaces it, and the server deletes its
  # criteria with it; this recreates them in the same apply.
  lifecycle {
    replace_triggered_by = [openporch_resource_definition.redis]
  }
}
```
