# openporch_environment_type (Resource)

An environment type, such as `staging` or `production`. Resource definitions match on it, and the `deployer` role is granted per type. It can only be deleted while no environment uses it. Import it by ID.

## Example Usage

```terraform
resource "openporch_environment_type" "staging" {
  id          = "staging"
  description = "Pre-production environments"
}
```
