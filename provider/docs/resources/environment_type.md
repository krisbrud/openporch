# openporch_environment_type (Resource)

An environment type, such as `staging` or `production`. Resource definitions match on it, and the `deployer` role is granted per type. It can only be deleted while no environment uses it. Import it by ID.

## Example Usage

```terraform
resource "openporch_environment_type" "staging" {
  id          = "staging"
  description = "Pre-production environments"
}
```

## Schema

### Required

- `id` (String) The type ID. Changing it replaces the type.

### Optional

- `description` (String) A description.
- `protected` (Boolean) Whether environments of this type are protected: a permit to delete, replace or detach resources there needs an administrator, and a change whose impact its driver cannot preview gets no permit. Only administrators change it. Defaults to `false`, so leaving it out unprotects a type protected outside OpenTofu.

## Import

Import it with `tofu import` or an `import` block, by the ID shown:

```shell
tofu import openporch_environment_type.staging staging
```
