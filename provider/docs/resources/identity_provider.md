# openporch_identity_provider (Resource)

An OpenID Connect provider people sign in with through `/auth/oidc/<id>/authorize`, like one under `[[oidc_login]]` in the server's configuration file, whose IDs cannot be used here. Changes apply to the next login without a restart. A `client_secret` is written to the built-in secret store and kept in the OpenTofu state, so protect the state. Deleting the provider stops sign-ins through it; members keep their `<issuer>:<sub>` identity. Import it by ID; an imported client secret is written again by the first apply that configures one. Needs a server with `/orgs/{org}/identity-providers`.

## Example Usage

```terraform
variable "corp_client_secret" {
  type      = string
  sensitive = true
}

# People sign in at https://porch.example.com/auth/oidc/corp/authorize.
resource "openporch_identity_provider" "corp" {
  id            = "corp"
  issuer        = "https://login.corp.example"
  client_id     = "openporch"
  client_secret = var.corp_client_secret
  callback_url  = "https://porch.example.com/auth/oidc/corp/callback"
  return_urls   = ["https://porch.example.com/"]

  # Lets `porch login --provider corp` finish on the loopback address.
  loopback_return = true
}
```

## Schema

### Required

- `callback_url` (String) This server's `/auth/oidc/<id>/callback` URL, as registered with the provider.
- `client_id` (String) The OAuth client ID registered with the provider.
- `id` (String) The provider ID in the login routes, a lowercase ID other than `github`. Changing it replaces the provider.
- `issuer` (String) The issuer, exactly as its discovery document and ID tokens name it. Changing it changes the identities it signs in, `<issuer>:<sub>`.

### Optional

- `algorithms` (List of String) The ID token signing algorithms accepted.
- `client_secret` (String, Sensitive) The client secret, written to the built-in store. Left out, the provider is a public client, which PKCE alone protects. Changing it writes a new version; `written_client_secret_ref` records the version written, and a secret changed outside OpenTofu plans a write of this one again.
- `loopback_return` (Boolean) Also return a finished login to any port of the loopback address, as `porch login --provider` listens on. Defaults to `false`.
- `return_urls` (List of String) The pages a finished login may return the browser to.
- `scopes` (List of String) The scopes requested, including `openid`.

### Read-Only

- `written_client_secret_ref` (Attributes) Where the client secret was written. (see [below for nested schema](#nestedatt--written_client_secret_ref))
