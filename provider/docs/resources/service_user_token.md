# openporch_service_user_token (Resource)

An API token of a service user. The server returns the token only when it is created, so it is kept in the OpenTofu state, which must be protected; see the provider documentation. A token cannot be changed: changing its description or expiry revokes it and issues a new one, which needs a new `id`. A token revoked outside OpenTofu leaves the state; issue it again under a new `id`, since a revoked token keeps its ID. Import it as `USER/TOKEN`; an imported token has no `token`.

## Example Usage

```terraform
# To rotate the token, change expires_at together with id.
resource "openporch_service_user_token" "ci" {
  user_id     = openporch_user.ci.id
  id          = "ci-2027"
  description = "GitHub Actions"
  expires_at  = "2027-01-01T00:00:00Z"
}
```
