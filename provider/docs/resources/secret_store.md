# openporch_secret_store (Resource)

An external secret store: AWS Secrets Manager or SSM Parameter Store, read and written with a cloud account. References name it in `store`. The region and account change in place; changing either makes openporch forget which secrets it created there. A store that is primary, or that anything still references, cannot be deleted. The built-in `openporch` store always exists and is not managed here. Import it by ID.

## Example Usage

```terraform
resource "openporch_secret_store" "vault" {
  id            = "vault"
  type          = "aws-secrets-manager"
  region        = "eu-north-1"
  cloud_account = openporch_cloud_account.aws.id
  primary       = true
}
```

## Schema

### Required

- `cloud_account` (String) The cloud account that reads and writes the store.
- `id` (String) The store ID. Changing it replaces the store.
- `region` (String) The AWS region, such as `eu-north-1`.
- `type` (String) `aws-secrets-manager` (a reference names a secret, a version is its `VersionId`) or `aws-ssm` (a reference names a parameter, a version is its number). Changing it replaces the store.

### Optional

- `primary` (Boolean) Marks the store primary, so new `{value}` secrets and drivers' secret outputs are written to it, when the store is created with `true` or changed to `true`. Marking first opens the store with its account, so it fails while AWS refuses the account's credentials. Only one store is primary: marking another store, here or outside OpenTofu, takes the mark away without this store being marked again, and `is_primary` shows it. `false` never unmarks a store, which stays primary until another one is marked; to switch, set the old store to `false` and the new one to `true` in the same change (or mark the built-in store with `PATCH /orgs/{org}/secretstores/openporch`).

### Read-Only

- `is_primary` (Boolean) Whether the store is the primary store now.
